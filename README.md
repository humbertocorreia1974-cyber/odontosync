# 🚀 OdontoSync

> Sistema de gestão multiunidade para clínicas odontológicas: agenda cirúrgica por cadeira e dentista, prontuário com odontograma interativo, orçamento por etapas com assinatura digital, controle de convênios com tabelas próprias, estoque por unidade, financeiro com comissão de dentista e painel consolidado do dono.

## 🛠️ Como Executar Localmente

```bash
# 1. Instalar dependências
npm install

# 2. Configurar variáveis de ambiente
cp .env.example .env # se aplicável

# 3. Iniciar servidor de desenvolvimento
npm run dev
```
